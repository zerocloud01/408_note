# 虚拟局域网
巨大的广播域会带来广播风暴和潜在的安全问题，并且难以管理维护。使用虚拟局域网技术可以将巨大的广播域分隔成若干较小的广播域

**虚拟局域网VLAN**是一种将局域网内的站点划分成**与物理位置无关的逻辑组**的技术，一个逻辑组就是一个VLAN，VLAN中各站点具有某些共同的应用需求

属于同一VLAN的站点之间可以直接进行通信，不同VLAN的战斗不能直接通宵

网络管理员课对局域网中各交换机进行配置来建立多个逻辑上独立的VLAN

**连接在同一交换机上的多个站点可以属于不同的VLAN，而属于同一VLAN的多个战斗可以连接在不同的交换机上**

虚拟局域网VLAN不是一种新型网络，只是局域网能够提供给用户的一种服务

## VLAN实现机制
最常见的是**基于以太网交换机的接口来实现VLAN**，这需要以太网交换机能实现：
-    能够处理带有VLAN标记的帧，也就是IEEE 802.1Q帧
-    交换机的各接口可以支持**不同的接口类型**，不同接口类型对帧的处理方式不同

### IEEE 802.1Q帧
也叫Dot One Q帧，它对以太网V2的MAC帧格式进行了拓展，在原地址和目的地址的类型之间插入了 **$4$ 字节VLAN标签字段**

![](./img/IEEE802.1Q帧.png)

-   **标签协议标识符TPID**：长度为16bit，值固定为 `0x8100`，表示该帧是IEEE 802.1Q帧
-   **优先级PRI**：长度为3bit，取值范围 $0\sim 7$，值越大优先级越高。**网络堵塞时，设备有限发送高优先级帧**
-   **规范格式指示符CFI**：长度为1bit
    -   0表示MAC地址以规范格式封装
    -   1表示MAC地址以非规范格式封装
    以太网取值为 $0$
-   **虚拟局域网标识符VID**：长度为12bit，取值范围 $0\sim 4095$，$0, 4095$ 保留不用
    是帧所属VLAN的标号，设备利用VID来识别帧所属VLAN。
    广播帧只在**同一VLAN**内转发

802.1Q帧一般不由用户主机处理，而是由交换机处理
-   当交换机收到**普通的MAC帧**，会给其插入**4B的VLAN标签**使之成为802.1Q帧，该处理简称打标签
-   当交换机转发802.1Q帧时，**可能会删除VLAN标签**使之称为普通MAC帧，该处理简称去标签。是否去表情取决于交换机接口类型

### 交换机接口类型
分为Access和Trunk

当交换机商店启动，若之前未对各接口进行VLAN先关配置，各接口默认为Access，默认缺省VLAN ID为1

#### Access
一般用于连接用户计算器，其**只能属于一个VLAN**，其PVID值域所属VLAN的ID相同

**接收**
一般只接受为打标签的MAC帧，根据接收帧的接口的PVID给帧打标签

**转发**
若帧中的VID值域接口的PVID值相同，则给帧去标签再进行转发

#### Trunk
一般用于**交换机间互连**，**其可属于多个VLAN**，即可通过属于不同VLAN的帧

**若互联的Trunk接口PVID值不同，可能出现转发错误**

**接收**
有无标签的帧都可以接收
-   若接收到到普通MAC帧，则根据其PVID打标签

**转发**
-   若帧VID等于接口PVID，则**去标签转发**
-   若帧VID不等于接口PVID，则**直接转发**
